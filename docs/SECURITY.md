# 安全说明

2FAuth Pocket 依赖用户配置的服务器生成验证码。服务器和设备的安全性都属于信任边界，应用不能替代恢复码、离线备用验证器或服务端安全维护。

## 连接与本地数据

- 只接受 HTTPS 地址，使用系统证书验证，不绕过 TLS 错误，不自动跟随 API 重定向。
- 服务器地址与 Personal Access Token 通过 Android Keystore 支持的 AES-GCM 加密保存。
- 不建立持久化账号数据库、验证码缓存或离线密钥库；不记录 Token 或完整服务端错误正文。
- 本地凭据加密与应用界面锁是不同机制，不应将界面解锁理解为每次都由生物识别硬件解密 Token。
- 清除本机连接或卸载应用不会撤销服务器 Token。丢失设备或怀疑泄露时，应在网页端撤销专用 Token。

## 密钥与二维码

普通列表请求显式禁用密钥返回。编辑账号、查看密钥和二维码需要新一次设备验证，并按需从服务器读取信息。

添加或扫码预览也会在内存中处理密钥。锁定时放弃敏感表单，不将其写入 Activity 保存状态。由于 Java 字符串和运行时内存管理的限制，不能保证密钥已被物理擦除。

账号二维码包含密钥，等同于凭据。不要截图、公开或发送给不可信服务。应用的连接、表单、扫描、二维码和底部弹窗始终设置截图保护；首页截图开关不取消这些保护。

## 图片与图标

相册二维码在手机本地识别，整张图片不上传；识别出的 `otpauth://` 信息发送至用户配置的服务器进行预览，确认后才保存账号。

扫描内容中的远程 `image` 指令会被移除。静态 SVG 图标不展开实体、不配置外部资源解析器，并拒绝 DTD、实体声明、脚本与 `foreignObject`。

## 验证码与网络错误

TOTP 有效期依据服务端生成时间、HTTP Date、网络延迟和设备单调时钟估算，并提前隐藏过期码。网络断开时不能生成新码。

HOTP 生成可能推进服务器计数器，应用仅在用户确认后请求，不在同步时自动生成。
对于 HOTP 和修改请求，超时或切到后台不代表服务器没有执行。应用不自动重试；请先在网页核对或同步后判断，避免重复操作。

## 剪贴板与设备保护

Android 13+ 会将复制内容标记为敏感。应用在验证码到期或复制后 30 秒尝试清除自身写入且未被替换的剪贴板内容。
Android 后台限制、进程被结束或其他应用行为可能阻止清理，因此剪贴板不是安全存储。

截图保护、加密存储和设备身份验证不能防护 root、恶意输入法、系统级截取或已被控制的设备。请使用可信设备，并及时安装系统安全更新。

## 反馈注意事项

报告问题时不要公开 Token、密钥、二维码、有效验证码或未脱敏的账号列表。
如果怀疑凭据泄露，应先撤销 Token；需要更换账号密钥时，按对应服务的恢复流程处理。
